应用功能与使用指南

📌 簡介

本應用是一款專為移動端打造的極簡記帳與隨身筆記雙合一工具。所有數據均採用本地緩存（localStorage）安全存儲，網頁刷新或重新打開後數據永不丟失。

💡 主要功能與更新說明

  • 記一筆（首頁）：支持選擇收支類型（支出/收入）。若支付方式選擇「學生卡」，則無論選擇什麼賬單類型均不顯示返利；若支付方式為學生卡以外且賬單類型選擇「吃喝、購物、生活、其他」時才显示返利選項。
  • 统计概览（日/周/月账单）：统计页支持在「日账单」、「周账单」、「月账单」三种维度间无缝切换。周账单置于日账单与月账单之间，并会严格根据你在上方周选择器中主动选择的周次（范围：周一至周日）来动态筛选和统计对应账单。
  • 詳情/編輯頁返利控制：可在明細的詳情頁中手動更改返利狀態。若選擇「無返利」（返利方式為「無」），則自動隱藏返利金額和返利方式兩項，且若原金額不為 0 會自動清零；若選擇有返利，則動態顯示返利金額和方式。
  • 降序排序（從上往下）：所有明細列表（包括主列表和統計下劃列表）均嚴格遵循——日期越晚越靠上，越早越靠下；同一天內序號越大越靠上，越小越靠下。
  • 隨身筆記：獨立的第四個 Tab 頁面，提供多行文本輸入框，輸入後點擊保存即可隨時記錄備忘。

🚀 使用方法

  1. 點擊底部導航欄可在【記帳】、【統計概覽】、【收支明細】和【筆記】之間自由切換。
  2. 首次進入或需要調整時，可在統計頁點擊“校准餘額”設置學生卡初始金額。
  3. 在明細列表中點擊任意賬單的“詳情”頁面可隨時修改或刪除記錄。
  4. 在任意頁面頂部左上角點擊【說明】按鈕即可隨時重讀本指南。

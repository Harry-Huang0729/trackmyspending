应用功能与使用指南

📌 简介

本应用是一款专为移动端打造的极简记账与随身笔记双合一工具。所有数据均采用本地缓存（localStorage）安全存储，网页刷新或重新打开后数据永不丢失，支持跨设备同步或本地持久化记录。

💡 主要功能与更新说明

  • 记一笔（首页）：支持选择收支类型（支出/收入），纯数字金额键盘输入。当支付方式选择“学生卡”时，支出项会自动隐藏“银行卡扣款”勾选；若同时选中【收入 + 其他 + 学生卡】三项时，会自动默认**取消勾选计入统计**且备注自动填充**“充值”**。一旦改变上述三项中的任意一项，系统会自动删除“充值”默认备注（若你手动改过其他内容则予以保留）并**重新勾选计入统计**。
  • 统计概览与下钻明细：支持按“日账单”或“月账单”维度查看。点击统计概览中的任意项目（汇总、分类、支付通道、返利总结）打开的全屏下钻账单明细页面，同样严格采用了与收支明细完全一致的降序排列。
  • 收支明细与下钻列表排序：已全面调整为统一的降序排列——日期越晚越靠上，越早越靠下；同一天内序号越大越靠上，越小越靠下（如最新日期和最大序号的记录在页面最顶部）。统计状态筛选默认设置为“全部”，并支持序号冲突警告红点与日期快捷跳转。
  • 随身笔记：独立的第四个 Tab 页面，提供多行文本输入框，输入后点击保存即可随时随地记录备忘。

🚀 使用方法

  1. 点击底部导航栏可在【记账】、【统计概览】、【收支明细】和【笔记】之间自由切换。
  2. 首次进入或需要调整时，可在统计页点击“校准余额”设置学生卡初始金额。
  3. 在明细列表中点击任意账单的“详情”按钮，可进入全屏页面随时修改或删除该笔记录。
  4. 在任意页面顶部左上角点击【说明】按钮即可随时重读本指南。
